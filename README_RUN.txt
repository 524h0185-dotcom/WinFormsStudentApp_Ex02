LAB 5 - EXERCISE 2

Project: WinFormsStudentApp

1. Open Ex02App.sln in Visual Studio 2022.
2. Build -> Rebuild Solution.
3. Press F5 to run.
4. Open View -> Git Changes.
5. Initialize Repository if Visual Studio does not detect the included local Git repository.
6. Create an empty GitHub repository named WinFormsStudentApp.
7. Do not initialize the GitHub repository with README, .gitignore, or license.
8. Add the GitHub repository as origin.
9. Commit and Push.

No SQL database is required for this exercise.
